# winboss

Minecraft 1.20.1 / Fabric 的整活 Boss 模组。

用四种颜色的火把在地上摆 2×2，右键任意一把召唤「微软」。血掉一半后会变成「巨硬」。

|  |  |
|---|---|
| 红石火把 | 铜火把 |
| 灵魂火把 | 火把 |

四把火把要四种颜色各一个，多了少了都不触发，也不会消耗。

## 技能

**微软**

- 火球
- 强制更新：蓄力 2.5 秒，期间无敌，结束炸一圈
- 开始菜单：召 2 只「④ 图标」小飞怪，场上最多 4 只

**巨硬**

- 三连火球
- 蓝屏死机：范围伤害 + 挖掘疲劳 + 缓慢 + 反胃
- 弹窗广告：失明 + 飘浮
- 自动修复：回血 18

## 安装

需要 1.20.1、Fabric Loader、Fabric API。jar 在 [Releases](https://github.com/YaM2026-boop/winboss/releases)。

## 编译

需要 JDK 17。

```
gradlew build
```

产物在 `build/libs/`。

## 其他

- 两阶段状态存进 NBT，存档重进还是巨硬
- 免疫击退，不受流体推动
- 全部是新增内容，没改原版任何东西
